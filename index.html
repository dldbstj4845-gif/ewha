Course Direction

Design the experience,
not just the screen.

UI 디자인의 기본 원리에서 시작해 리서치, 정보 구조, 인터랙션, 프로토타이핑 그리고 AI를 활용한 빠른 구현까지 연결합니다.

01

Observe

사용자의 행동과 문제를 관찰하고, 인터페이스가 해결해야 할 핵심 경험을 정의합니다.

02

Structure

정보 구조, 레이아웃, 타이포그래피와 디자인 시스템을 통해 명확한 화면 구조를 만듭니다.

03

Prototype

Figma와 코드 기반 프로토타이핑을 오가며 아이디어를 실제로 작동하는 경험으로 발전시킵니다.

Curriculum

From fundamentals
to working interfaces.

한 학기 동안 UI 디자인의 기본기와 실험적인 제작 방식을 함께 다룹니다.

01–03
UI Fundamentals

사용자 인터페이스의 역할, 좋은 UI의 조건, 시각적 위계, 타이포그래피와 레이아웃.

04–06
User Flow & Information Architecture

사용자 시나리오, 화면 흐름, 내비게이션 구조와 와이어프레임 설계.

07–09
Components & Design System

재사용 가능한 컴포넌트, 상태와 변형, UI 패턴과 간단한 디자인 시스템 구축.

10–12
Interaction & Prototyping

마이크로 인터랙션, 전환, 피드백, Figma 프로토타입을 활용한 경험 검증.

13–15
Vibe Coding & Final Project

AI 기반 코딩 도구를 활용해 디자인 의도를 빠르게 구현하고, 최종 인터페이스를 완성.

Vibe Coding

Prompt, make, test,
and refine.

코드를 처음부터 완벽히 작성하는 것이 목표가 아닙니다. 아이디어를 자연어로 설명하고, AI와 함께 HTML/CSS/JavaScript 기반의 프로토타입을 만들면서 디자인과 구현 사이의 거리를 좁혀봅니다. 결과를 그대로 받아들이기보다, 디자이너의 관점으로 수정하고 판단하는 과정에 집중합니다.

Prompting HTML / CSS Rapid Prototyping AI-assisted Coding Design Critique
Final Outcome

One idea,
one working experience.

학기 말에는 하나의 명확한 문제를 선택하고, 디자인부터 구현까지 직접 연결합니다.

PROCESS

Research → UI → Prototype

문제 정의, 사용자 흐름, 인터페이스 설계, 프로토타입 테스트의 전 과정을 기록합니다.

OUTPUT

Interactive Final Project

Figma 프로토타입 또는 vibe coding을 활용한 웹 기반 인터랙티브 결과물을 완성합니다.
